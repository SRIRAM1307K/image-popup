
## 📷 Simple Image Gallery

This is a lightweight image gallery built using **HTML**, **CSS**, and **JavaScript**. It displays a grid of images that users can click to view in a larger popup. The popup can be closed by clicking a close button or anywhere outside the enlarged image.

### ✨ Features
- Responsive image grid layout
- Click-to-enlarge functionality
- Smooth image zoom popup
- Easy-to-close overlay

### 🚀 How to Use
1. Clone or download the repository.
2. Open the `index.html` file in your browser.
3. Click on any image to view it in a larger popup.
4. Close the popup by clicking the **×** button or anywhere outside the image.

### 🛠️ Technologies Used
- HTML5
- CSS3 (Grid, Transitions)
- Vanilla JavaScript
